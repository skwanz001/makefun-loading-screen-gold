One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer — written to `/output/entry.txt` by a stdlib-only Python program.

The tip: *"Tip: your agent isn't stuck — it's in a meeting with itself about whether to ask you or just guess. Spoiler: it guessed."* (120 characters)

## Run it

```sh
python3 main.py
```

Writes the tip to `/output/entry.txt` (UTF-8, one line, 1–200 characters).
